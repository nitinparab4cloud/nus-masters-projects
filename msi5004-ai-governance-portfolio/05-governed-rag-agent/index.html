Governed AI Helpdesk Agent

Answers AI-governance policy questions only from a fixed, cited corpus, and routes new AI-system registrations through a risk-tiered human-approval gate with a tamper-evident audit trail. Every message is screened for prompt-injection attempts before anything else runs, and the agent can call exactly one tool. This static page is a line-for-line JS port of the Python engine in the repo — no server, no network calls, everything runs in your browser.
