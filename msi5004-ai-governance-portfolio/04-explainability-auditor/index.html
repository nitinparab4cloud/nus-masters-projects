Explainability Auditor

Per-person, plain-language explanations of an AI risk-classification decision, using the same ProPublica COMPAS dataset audited for group-level fairness in Project 2 of this series — this time answering the individual question: why was this specific person flagged?

This explains a surrogate model's approximation of COMPAS, not COMPAS's actual proprietary logic — no outside party has access to that. A transparent logistic regression was trained on COMPAS's own publicly known, race-blind input features to approximate its high-risk flag; the explanations below are exact Shapley/SHAP-style attributions for that surrogate, not an approximation. Race is never used as a model input; where shown, it is context only.
