# NUS Masters Projects

Coursework projects from Nitin Parab's MSc in AI and Innovation at the National University of Singapore (NUS), expected December 2026.

| Project | Course | Summary |
|---|---|---|
| [Fraud Detection in Electricity & Gas Consumption](fraud-detection-electricity-gas-msi5001/) | MSI5001 — Introduction to AI | Binary classification system to flag fraudulent utility customers. Voting ensemble (RF + XGBoost + LR) reaches 0.792 ROC-AUC and catches 65% of fraud by reviewing 25.4% of customers — a 124% ROI. |
| [Handwritten Digit Recognition (MNIST)](mnist-digit-recognition/) | Machine Learning coursework | Compares KNN, Logistic Regression, MLP, and CNN on MNIST digit classification, plus a PCA vs. t-SNE analysis. CNN reaches 99.29% test accuracy. |
| [Decoding Justice: ML Analysis of Old Bailey Criminal Proceedings](decoding-justice-old-bailey-ll5532x/) | LL5532X — Law, Algorithms, and AI | Group project (full team credited in the README) applying NLP/ML to 9,192 historical criminal trials to study verdict prediction, gender bias in sentencing, and punishment prediction — and the bias-propagation pipeline linking them. |

Each project folder is self-contained with its own README covering the problem, approach, results, and how to run it.
